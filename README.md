## 🎯 Comment ça marche

1. Scannez le QR code avec votre téléphone
2. Remplissez le formulaire (tous les champs ne sont pas obligatoires)
3. Cliquez sur "Envoyer"
4. Les données sont enregistrées automatiquement dans NocoDB

## 🔧 Technique

- **Frontend** : HTML/CSS/JavaScript vanilla
- **Backend** : NocoDB (API REST)
- **Hébergement** : GitHub Pages
- **Données** : https://sheets.viegratuitepourtous.tech
